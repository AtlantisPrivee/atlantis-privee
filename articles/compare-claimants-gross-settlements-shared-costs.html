How to Compare Claimants’ Gross Settlements With Shared Case Costs

✍️ Atlantis Editorial 📅 November 10, 2026 ⏱ 2 min read

Several people settled claims from the same case and one invoice was shared. Begin with each claimant's gross amount and then trace the basis for dividing that invoice. The gross shares, fees and individual costs can differ even when everyone is affected by the same shared expense.

Identify each allocation before comparing net payments

Use the settlement breakdown, applicable fee agreements and cost ledger. Separate each person's gross share, individually assigned costs and fees. Put genuinely shared costs in a separate group with the underlying invoice and the allocation rule used. Ask which agreement, written approval or other authority supplies that rule for the case.

California Rule 1.8.7 addresses aggregate settlements by a lawyer representing multiple clients. It generally requires each client's informed written consent, with disclosure of the claims involved and each person's participation, and excludes class action settlements subject to court approval. ABA Model Rule 1.8(g) provides a related model rule. Applicable obligations depend on the jurisdiction and representation. California rule on aggregate settlements · ABA Model Rule 1.8(g)

Compare the outcomes with a shared invoice

Suppose two hypothetical gross shares are $36,000 and $24,000 and one expert invoice totals $1,200. If the approved allocation is proportional to gross proceeds, the shares are 60% and 40%, so the costs are $720 and $480. If the applicable arrangement divides the invoice equally, each share is $600. Both approaches reconcile to $1,200. The $120 shift for each person comes from the allocation rule, and the example leaves other deductions aside.

Then check whether the fee on each share uses gross proceeds or a base after eligible costs. Ask for the calculation before comparing individual checks. If one person advanced the expert's bill, find the reimbursement entry and check whether the allocation reflects that advance.

Reconcile the separate statements to the shared total

Use the Pro Rata Allocation Calculator to organize gross shares when there is a shared pool, then compare the cost allocations with the actual invoices. If one cost was withheld from just one payment, trace that cost back to the receipt. If the firm disbursed the payments through trust, compare the relevant transactions with each client's accounting.

Ask for the Native Crash Video Before You Measure Frame Timing

✍️ Atlantis Editorial 📅 November 7, 2026 ⏱ 3 min read

A shop emails a short MP4 labeled “30 fps.” You need to know how much time passed between two visible events. Ask for the closest available export to what the recorder stored, along with information about its clock and export settings. A frame rate reported for a shared copy may describe that copy's playback.

Send the camera owner a request they can act on

Identify the camera location, direction and a time window in local time. Ask the owner to preserve and export the native or original-quality recording for that window, with its normal player or instructions if the format requires one. Ask whether the export was converted, trimmed or screen-recorded and whether an on-screen time is generated by the recorder or the export software. Request any existing time zone or clock-offset information.

SWGDE's video analysis guidance describes obtaining the best available original data and documenting processing. If a conventional playable copy is the only version immediately available, keep it and record how it was provided while following up for the source export. SWGDE best practices for digital forensic video analysis

Distinguish playback rate from the time between frames

Consider an illustrative file. The displayed timing metadata reports one frame at 18.410 seconds and another at 18.760 seconds. Their reported separation is 0.350 seconds. Counting 15 frame intervals at an assumed 30 frames per second would instead yield 0.500 seconds. Which timing represents the source recording depends on how the camera recorded and how the file was created.

For supported ISO base media formats, SWGDE explains how presentation timestamps can describe intervals between specific displayed frames. It also discusses limitations introduced by some exports and the role of an external timing reference. A camera's visible wall-clock overlay is another record that may need alignment. SWGDE guidance on frame timing in ISO base media formats

Keep a record of the exact file you received

Save the original filenames, how and when each file arrived, the camera identity and the sender's export notes. Calculate a checksum of the preserved file if you need to match an analysis copy against it. The SHA-256 File Checksum Tool helps compare the bytes of two copies. The file source and clock accuracy still depend on the underlying evidence.

When the footage will be compared with traffic-controller events, use the crosswalk timing records guide. For a recording that could help place a dog and delivery worker at a particular moment, see the New York gate-latch evidence guide.

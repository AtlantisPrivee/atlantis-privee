How to Match an EOB Claim Number With a Radiology Bill

✍️ Atlantis Editorial 📅 November 10, 2026 ⏱ 2 min read

A radiology bill lists an account number and a health plan notice lists a claim number. Those identifiers can describe the same work in two different systems. Start with the service and who billed it. A single scan may lead to a facility charge and a separate charge for the clinician's interpretation.

Find the exact billing entity

Record the date, the facility, the exam description and the name on the itemized bill. Ask the billing office for the billing provider, any provider identifier it can share, the code or component billed and the payer claim reference returned on the remittance. Ask the insurer to search by date and billing entity if the claim number is unavailable. CMS identifies the provider, service description and claim reference as fields to check on an EOB. CMS guide to EOB fields

Some radiology services have professional and technical components. CMS's Medicare manual describes component billing and modifiers for eligible services. If a bill refers to an interpretation or a technical component, ask which was billed and use the coding details the provider gives you. Plan rules and claim presentation can vary. CMS Medicare radiology billing manual

Check the amount only after the match

For example, the insurer shows a $45 patient amount on an imaging center claim. A separate $35 bill comes from the radiologist who read the scan. Both may share the scan date. Ask whether the $35 bill corresponds to a different claim and which EOB explains that amount. The identical date gives you a starting point for the search.

Record the link as “radiology account R14 corresponds to plan claim 8124,” with the name and date of the confirmation. Then compare the EOB's patient amount with any payments or credits on that account. Keep the facility and interpretation in separate rows.

When a second bill lists the same imaging description, ask for the service code and billing entity for both entries. A match on the date and exam is a starting point. The component, provider and payer reference complete the comparison.

Send a short matching request

Use the Records Request Letter Builder to list the account, scan date and identifiers you need. For a statement sent by a billing company, verify the provider behind the account. If one invoice spans several dates, reconcile each line before totaling them.

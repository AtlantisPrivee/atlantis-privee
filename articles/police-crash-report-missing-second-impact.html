The Police Crash Report Leaves Out a Second Impact

✍️ Atlantis Editorial 📅 November 7, 2026 ⏱ 3 min read

A report describes one rear-end strike. You remember a second impact, perhaps when your car was pushed into another vehicle. Start by locating the exact omission. A second contact can appear in the unit-level event fields even when the narrative summarizes the crash in one sentence.

Read the report as a set of records

Obtain the report with its continuation pages and any available supplement. Match each unit number to the vehicles involved. Check the written narrative, diagram and event codes separately. An entry labeled first harmful event identifies the first injury- or damage-producing event within the reporting framework. Other fields can capture later events. Use your agency's code sheet. The federal MMUCC provides voluntary crash-reporting guidance, and the local form controls what a particular field means. NHTSA's Model Minimum Uniform Crash Criteria

Show exactly which contact is missing

Write one line per reported contact. For example, “Impact A: Unit 3 struck the rear of Unit 2. Impact B: Unit 2 contacted the rear of Unit 1 after being pushed forward.” Mark the source for each statement. Identify what you personally felt, what a witness saw, what a video shows and which damage photos are merely consistent with a contact.

If you have two short clips, keep the original exports and identify the clock used by each. Two images of the same damage can show condition while leaving the order unresolved. For timing evidence, see how to ask for native crash footage. If a witness saw only the first collision, preserve the limits of that observation.

Send the request to the agency that wrote the report

Ask how the investigator accepts supplemental evidence. Include the report number, unit numbers, disputed passage, a short factual chronology and the best supporting record. Request the procedure and, if a supplement is issued, a copy. Texas's CR-100 manual gives a concrete example. It instructs investigators to use a supplemental report when they need to amend a report already sent to TxDOT or provide additional information. Local procedures vary. TxDOT crash-report instructions, Section 5

In report 1234, Unit 2's event sequence ends with the rear impact. Please review the attached original video and the still indexed at 14:08:16 showing Unit 2 contacting Unit 1. Please tell me how I can submit this for the investigator's review.

Use the Records Request Letter Builder to format the request. Keep the original report with any supplement and give the insurer both versions, with a dated note identifying the change. If the second driver left and the file depends on proof gathered later, see how to use tow records in a hit-and-run claim.

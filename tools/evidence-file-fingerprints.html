How this tool works

The browser reads each selected file and computes its SHA-256 digest, using the Web Crypto API when available or a local JavaScript fallback. The export includes the name, byte size, file-reported modified time, and hash.

What to check

This is not notarization, authentication, a chain-of-custody certification, or proof of capture time. Keep a separate handling log and preserve original files.

Worked example

Fingerprint an original and a working copy: matching hashes indicate matching bytes, while an edited copy will normally produce a different hash.

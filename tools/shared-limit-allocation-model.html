What this tool helps you do

Explore a hypothetical pro-rata split of a limited pool across multiple entered requests. A $50,000 pool against $100,000 of total entered requests produces a 50% proportional illustration.

How the result is built

If requests exceed the pool, each request is multiplied by pool ÷ total requests. If they do not exceed the pool, each request is left unchanged.

What to check before relying on it

Actual policy language, per-person limits, allocation agreements, priorities, and legal rules are not modeled. This tool does not determine coverage or entitlement.
